# 🎵 Ikel — Portfólio Musical

Bem-vindo(a) ao meu portfólio musical! Este site reúne as músicas que já produzi/compus, com o objetivo de compartilhar meu trabalho e minha trajetória como artista.

🔗 **Acesse o site:** [Clique aqui](https://micael569.github.io/portifolio-musical)

## 🎧 Sobre o projeto

Este é um site pessoal onde reúno minhas produções musicais em um só lugar — faixas, links para plataformas de streaming e um pouco sobre cada projeto. A ideia é facilitar para que qualquer pessoa possa conhecer meu trabalho de forma organizada e acessível.

## 🎼 O que você encontra por aqui

- Player/lista com as músicas já lançadas
- Links diretos para Spotify, YouTube, Instagram, etc.
- Um pouco sobre cada faixa/projeto (data, estilo)
- Formas de entrar em contato

## 🛠️ Tecnologias utilizadas

- CSS3
- JavaScript
